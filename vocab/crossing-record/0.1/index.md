# seam:CrossingRecord 0.1

Vocabulary namespace for the Form C unified crossing-record base shape.

**IRI:** `https://jediwright.github.io/seam-stack/vocab/crossing-record/0.1#`

This namespace defines the base shape that all governed-event records in the
Seam Stack architecture instantiate: gate-check records, schema lineage records,
AI provenance records, and code-change verification tags.

Part of the [Seam Stack](https://www.systemsofthought.com/seam-stack/) — a
four-layer architectural pattern for local-first systems where the seam, not
the server, is the primary design surface.
