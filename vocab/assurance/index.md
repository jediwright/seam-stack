# Seam Stack Canonical Assurance Scale

Vocabulary namespace for the 1–5 canonical assurance scale referenced by
`seam:credentialContext`.

**IRI:** `https://jediwright.github.io/seam-stack/vocab/assurance/`

Defines the canonical assurance levels used to normalize identity credential
assurance across jurisdictions and regulatory regimes. The scale is a useful
approximation for triage; bundles record the underlying native regime assurance
level alongside the canonical value.

Part of the [Seam Stack](https://www.systemsofthought.com/seam-stack/) — a
four-layer architectural pattern for local-first systems where the seam, not
the server, is the primary design surface.
